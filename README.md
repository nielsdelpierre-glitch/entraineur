# L’ENTRAÎNEUR — version 4

## Mise à jour
Téléversez les fichiers à la racine du dépôt GitHub Pages et remplacez les anciens fichiers. Gardez les deux PNG dans le dossier `icons/`. Puis faites **Commit changes**.

## Course à pied
La fiche Course propose désormais distance en km, durée en minutes, type de course et nombre de séries/intervalles. Chaque série peut contenir répétitions, durée et récupération.

## Autres fonctions
- Détail des séances de force avec séries et répétitions modifiables.
- Fiche escalade : choisir le nombre de voies puis une cotation pour chaque voie, ou « Blocs ».
- Enregistrement des séances et historique.
- Export/import JSON pour sauvegarder les données.

## Publication
GitHub → Settings → Pages → Deploy from a branch → `main` et `/ (root)`.
Ouvrez ensuite l’URL GitHub Pages sur iPhone dans Safari et rechargez.

Les données restent dans le stockage local du navigateur. Exportez régulièrement une sauvegarde JSON.
